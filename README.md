# מנוע תמהילי קרנות השתלמות (Profit Mix Optimizer)

האפליקציה קוראת **רק** את קבצי האקסל שמצורפים בתוך הפרויקט (Single Source of Truth):
- `data/קרנות השתלמות פברואר 2026.xlsx`  (מסלולים/חשיפות)
- `data/ציוני שירות.xlsx`  (דירוג שירות)

> משתמשי הקצה **לא** מעלים קבצים ולא יכולים לשנות את הנתונים.

## מבנה קבצים (כמו שצריך להיות בריפו)
```
app.py
requirements.txt
data/
  קרנות השתלמות פברואר 2026.xlsx
  ציוני שירות.xlsx
```

## פריסה ב‑Streamlit Community Cloud
1. העלה לריפו בדיוק את הקבצים/התיקיות שב‑ZIP (כולל `data/` וה‑xlsx שבתוכה).
2. ודא ש־`requirements.txt` כולל **רק** שמות חבילות (בלי טקסט/Markdown/```).
3. ב‑Streamlit Cloud: Deploy → Advanced settings → בחר Python 3.11 או 3.12 (מה שעובד אצלך), ואז Deploy.
4. אם יש שגיאת התקנת חבילות: בדוק שלא הדבקת בטעות טקסט לתוך `requirements.txt`.
